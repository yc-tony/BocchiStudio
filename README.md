# Bocchi Studio 
(Virtual Cover Studio)

## 📌 專案願景与核心定位
這是一個**專為社群短影音（YouTube Shorts, IG Reels, TikTok）創作者打造的輕量化網頁虛擬錄音室**。
傳統錄製 Cover 影片需要繁瑣的錄音軟體（DAW）設定、音訊對齊與剪輯軟體後製。本專案透過「網頁化」與「AI 技術」，讓創作者只要貼上 YouTube 連結，就能在瀏覽器內完成一鍵錄音、錄影、樂器消音、自動合成並匯出。

### 核心亮點：
* **零伺服器成本（$0 Inframind）：** 影音合成完全在使用者的瀏覽器端（Client-side）利用 CPU 運算，伺服器不消耗任何頻寬與儲存空間。
* **無限音樂庫：** 內嵌 YouTube 播放器，使用者免下載音檔，貼上網址即刻開始。
* **AI 樂器分離變現：** 完美的付費解鎖卡點（Paywall），提供獨立音樂人「抽離特定樂器自彈自唱」的剛性需求。

## 🛠️ 技術選型 (Tech Stack)

| 項目 | 技術 / 工具 | 理由 |
| :--- | :--- | :--- |
| **前端框架** | Next.js (React) | 良好的 SEO（利於藝人頁面推廣）與優秀的組件架構。 |
| **音訊硬體擷取** | Web Audio API | 免安裝驅動，直接網頁偵測使用者的錄音介面或麥克風輸入。 |
| **影音即時錄製** | MediaRecorder API | 同時擷取攝影機畫面與音訊輸入，生成在地暫存軌。 |
| **音訊解析** | **Cobalt API (免費/開源)** | 免登入解析 YouTube 網址，直接獲取純音訊 (Audio Stream) 連結。 |
| **在地影音合成** | FFmpeg.wasm | 在瀏覽器內將錄好的影片與 YouTube 背景音樂結合，不透過後端。 |
| **AI 樂器分離** | Demucs V4 via Replicate API | 按次計費的雲端 GPU API，使用者付費才觸發，轉嫁成本。 |
| **資料庫與會員** | Supabase (Free Tier) | 僅儲存使用者帳號與付費狀態，幾乎不耗費流量。 |

## 🔄 核心工作流程 (Workflow)
[使用者貼上 YT 連結]
│
▼
[呼叫 Cobalt API] ───> 獲取 YouTube 純音訊 Blob (背景音樂)
│
├─ (免費版) ──────────────────────────┐
└─ (付費版) ─> [呼叫 AI API 分離樂器] ─> 移除吉他/鼓軌
│
┌─────────────────────────────────────────┘
▼
[開啟虛擬工作室 UI] ───> 使用者選定錄音介面輸入孔、戴上耳機
│
▼
[開始錄製] ───> 網頁同步播放 YT 影片 ＋ 錄製使用者麥克風與攝影機 (MediaRecorder)
│
▼
[在地合成] ───> FFmpeg.wasm 將「YouTube 音訊」與「使用者錄影」在瀏覽器黏合
│
▼
[觸發下載] ───> 產生 .mp4 檔案直接下載到手機/電腦，專案主機 $0 頻寬消耗

## 規劃商業模式
專案不收取基本的網站使用費，而是採用 功能型單次付費 / 訂閱解鎖：

免費版 (Free Tier)：

可無限次貼上 YouTube 連結並同步錄製 Cover。

免費匯出標準社群格式影片。

無法消除原曲中的樂器。

Premium 樂器分離功能 (加值服務)：

計費方式： 單次購買（例如：$30 台幣/首）或 訂閱制（例如：$149 台幣/月，限額 20 首）。

技術卡點： 當使用者按下「消去吉他」或「消去人聲」時，前端將 Cobalt API 抓到的音訊上傳至 Replicate (Demucs V4) 進行分軌處理，處理完後再傳回前端供使用者錄製。
