# Bocchi Studio 
(Virtual Cover Studio)

本專案是一個專為社群短影音創作者打造的輕量化網頁虛擬錄音室。核心概念為：**「專門拍 Cover 的輕量化瀏覽器 DAW，支援 VST2 插件與獨家商城音效，用使用者的手機算力省下伺服器頻寬費，最後靠 AI 樂器分離卡點變現。」**

---

## 1. 這個網頁是幹嘛的？

這是一個**「線上的虛擬音樂錄音室（DAW）」**，專門為想在 Instagram Reels、YouTube Shorts 或 TikTok 上發表音樂 Cover（翻唱或樂器翻奏）的愛好者設計。

傳統上，製作一首高品質的 Cover 影片門檻極高，必須同時精通專業錄音軟體（DAW）、設定錄音介面，還要使用剪輯軟體手動對齊影音。

**本網站提供一個簡潔的瀏覽器內 DAW 介面，包含以下核心功能：**

### 音軌
* **背景音樂音軌（Background Track）：** 使用者自行上傳伴奏音檔（MP3、WAV 等），作為 Cover 的背景伴奏。
* **錄音音軌（Recording Track）：** 偵測並擷取使用者的麥克風或專業錄音介面輸入，記錄人聲或樂器演奏。
* **VST2 插件支援：** 使用者可在音軌上掛載自己本機安裝的 VST2 插件（如等化器、壓縮器、混響效果等），在瀏覽器環境中直接套用。

### 影片軌
* **攝影機錄影軌（Camera Track）：** 開啟裝置攝影機，在錄音的同時同步錄製影像，與音軌精準對齊。

### 完整流程
1. **上傳背景音樂：** 使用者上傳自備的伴奏音檔。
2. **掛載插件（選用）：** 在音軌上掛載自己的 VST2 插件，或從 Bocchi 商城購買並套用專屬外掛音效。
3. **同步錄製：** 戴上耳機，一邊聆聽背景音樂，一邊對著攝影機唱歌或彈奏樂器。
4. **在地合成：** 錄製完成後，DAW 自動將所有音軌與影片軌在本地端黏合。
5. **對嘴微調：** 透過滑桿微調影音延遲後，直接下載成品影片發布至社群平台。

## 2. 會用到什麼工具（背後的運作秘密）？

為了達成 **「$0 伺服器頻寬與儲存費用」** 的商業營運，本專案將運作效能完全轉嫁至客戶端瀏覽器，主要運用以下工具：

* **Next.js (網頁外殼)：** 用於架設整個網站的前端介面，設計成擬真、具有儀式感的專業錄音室控制台。
* **瀏覽器內建功能 (聲音與錄影)：** 利用 Web Audio API 與 MediaRecorder API，直接偵測並擷取使用者的麥克風、專業錄音介面輸入源，並開啟攝影機錄影。
* **VST2 Plugin 橋接（Web Audio Worklet）：** 透過 AudioWorklet 或 WebAssembly 橋接層，讓使用者自備的 VST2 插件能掛載至瀏覽器音訊處理鏈上。
* **Bocchi 商城插件系統（DRM 保護）：** 使用者可在平台內建商城購買官方提供的外掛音效插件。這些插件採用伺服器端授權驗證，**只能在 Bocchi Studio 服務內使用**，無法被匯出至其他 DAW 或外部環境。
* **FFmpeg.wasm (瀏覽器秘密武器)：** 嵌入在網頁中的微型剪輯核心。完全利用**使用者自己的手機或電腦算力**在本地端進行影音黏合，創作者不需要上傳大體積影片，幫網站省下巨額的雲端帳單。
* **Replicate / Demucs (AI 消音大師)：** 專案中唯一的雲端付費工具。負責利用 AI 將歌曲拆解成多個獨立軌道（人聲、鼓、貝斯、其他樂器）。

## 3. 商業與獲利模式（怎麼賺錢？）

網站採用 **「基礎功能免費，進階功能與商城變現」** 的低風險商業模式：

* **免費版功能（獲取海量用戶）：** 使用者可無限次上傳伴奏音檔、錄音錄影、合成並下載影片。此舉能吸引龐大的社群音樂愛好者進駐，為網站帶來病毒式的口碑傳播。

* **商城外掛音效銷售（核心收益來源）：** 使用者可在 Bocchi 商城內購買官方提供的音效插件（如特定風格的混響、壓縮器、專屬音色包等）。這些插件採平台授權鎖定，**只能在 Bocchi Studio 服務內使用**，形成平台獨家護城河。
  * **方案設計：** 可採用「單次買斷」或「訂閱制解鎖全部插件」。

* **付費解鎖 AI 消音（加值服務）：** 當使用者需要**「消音/抽離樂器」**時即觸發付費牆。例如：吉他手想錄製 Cover，希望消除原曲中的吉他聲，只留下原唱人聲和鼓聲來幫自己伴奏。
  * **收費結構：** 可採用「單次購買（如：30 元台幣/首）」或「月費訂閱制（如：150 元/月，可消音 20 首歌）」。
  * **優勢：** 雲端 AI 分離（Replicate）採非同步按秒計費（單次成本僅約台幣幾毛錢）。只有在使用者確認執行時才觸發 API，開發者擁有極高的利潤空間，且完全沒有固定伺服器開銷。
