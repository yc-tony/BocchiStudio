# Bocchi Studio 
(Virtual Cover Studio)

本專案是一個專為社群短影音創作者打造的輕量化網頁虛擬錄音室。核心概念為：**「用 YouTube 當作免費的無限音樂庫，用使用者的手機算力省下伺服器頻寬費，最後靠 AI 樂器分離卡點變現。」**

---

## 1. 這個網頁是幹嘛的？

這是一個**「線上的虛擬音樂錄音室」**，專門為想在 Instagram Reels、YouTube Shorts 或 TikTok 上發表音樂 Cover（翻唱或樂器翻奏）的愛好者設計。

傳統上，製作一首高品質的 Cover 影片門檻極高，必須同時精通專業錄音軟體（DAW）、設定錄音介面，還要使用剪輯軟體手動對齊影音。

**本網站將繁瑣流程簡化為四個步驟：**
1. **貼上連結：** 使用者打開網頁，貼上任何一條 YouTube 網址。
2. **同步錄製：** 使用者戴上耳機，一邊看著 YouTube 影片，一邊對著手機或電腦的攝影機開始唱歌或彈奏樂器。
3. **在地合成：** 錄製完成後，網頁會自動將「使用者的歌聲/吉他聲」與「YouTube 的音樂」完美黏合。
4. **對嘴微調：** 使用者透過滑桿微調對嘴延遲後，即可直接下載成品影片，即時發布至社群平台。

---

## 2. 會用到什麼工具（背後的運作秘密）？

為了達成 **「$0 伺服器頻寬與儲存費用」** 的商業營運，本專案將運作效能完全轉嫁至客戶端瀏覽器，主要運用以下工具：

* **Next.js (網頁外殼)：** 用於架設整個網站的前端介面，設計成擬真、具有儀式感的專業錄音室控制台。
* **瀏覽器內建功能 (聲音與錄影)：** 利用 Web Audio 與 MediaRecorder API，直接偵測並擷取使用者的麥克風、專業錄音介面輸入源，並開啟攝影機錄影。
* **Cobalt API (音樂解析器)：** 免費開源的第三方工具。負責在背景解析使用者貼上的 YouTube 網址，瞬間抓取純音訊檔（MP3）下載至使用者的瀏覽器暫存，作為伴奏。
* **FFmpeg.wasm (瀏覽器秘密武器)：** 嵌入在網頁中的微型剪輯核心。完全利用**使用者自己的手機或電腦算力**在本地端進行影音黏合，創作者不需要上傳大體積影片，幫網站省下巨額的雲端帳單。
* **Replicate / Demucs (AI 消音大師)：** 專案中唯一的雲端付費工具。負責利用 AI 將歌曲拆解成多個獨立軌道（人聲、鼓、貝斯、其他樂器）。

## 3. 商業與獲利模式（怎麼賺錢？）

網站採用 **「基礎功能免費，高階 AI 功能按次扣點/訂閱」** 的低風險商業模式：

* **免費版功能（獲取海量用戶）：** 使用者可無限次匯入 YouTube 連結、戴耳機錄音錄影、合成並下載影片。此舉能吸引龐大的社群音樂愛好者進駐，為網站帶來病毒式的口碑傳播。
* **付費解鎖卡點（加值服務）：** 當使用者需要**「消音/抽離樂器」**時即觸發付費牆。例如：吉他手想錄製 Cover，希望消除原曲中的吉他聲，只留下原唱人聲和鼓聲來幫自己伴奏。
* **收費與成本結構：** * **方案設計：** 可採用「單次購買（如：30 元台幣/首）」或「月費訂閱制（如：150 元/月，可消音 20 首歌）」。
    * **優勢：** 雲端 AI 分離（Replicate）是採非同步按秒計費（單次成本僅約台幣幾毛錢）。只有在使用者的帳戶內有點數且確認執行時才會觸發 API，開發者擁有極高的利潤空間，且完全沒有「沒人使用卻要養昂貴伺服器」的固定開銷。
